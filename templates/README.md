# Adding a new post
1. Copy `article-template.html` to `articles/<slug>.html`, replace ARTICLE TITLE / SLUG / description / body / Sources.
2. Recipes: change the tag to "Recipe" and remove the "Researched guide" note. First-hand visits: change the note to "First-hand visit".
3. Add the image as `assets/img/<slug>.jpg` (1200x750).
4. Add a card to `index.html` and `guides.html` or `recipes.html` (copy an existing `<a class="card">`).
5. Add a `<url>` to `sitemap.xml`.
